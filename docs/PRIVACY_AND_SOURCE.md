# Privacy and Source

## Source code

The production source is private. This repository contains documentation, diagrams and screenshots only. No licence to the source is granted; see [RIGHTS.md](../RIGHTS.md).

## Sensitive configuration

Sensitive configuration exists (API keys, signing material, backend configuration files) and is excluded from this repository.

## Data handled by the app

- **Location**: approximate location from an IP lookup, or a city the user enters manually, used only to request local weather.
- **Preferences**: display and mode settings stored on the device.
- **Purchases**: product identifiers and premium status.
- **Analytics and crash reports**: sent through Firebase in the TV build; compiled out in the phone build.
- **Ads**: AdMob (phone) and Unity Ads (TV) may process advertising identifiers under their own policies.
